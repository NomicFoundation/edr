Memory over time — hardhat test solidity step-trace fix (EDR PR #1560)

RSS of a single process running the 16 heavy fuzz suites 4× in a loop (64 arena alloc/drop cycles), sampled every 20 ms. This is the "memory graph over time" — and it tests the specific worry: does the fix net-reduce memory, or does it just get jagged while trending to the same place?

Answer: it's jagged (as predicted) and it nets a real reduction. The unfixed line climbs to a high plateau and stays there (mimalloc keeps freed pages); the fixed line saw-tooths — each suite's mi_collect returns pages — and ends far lower. More loops make the unfixed plateau higher, while the fixed envelope stays bounded.
